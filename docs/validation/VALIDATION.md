## 独立走查与修正

一个独立评估代理以无会话工具、仅维护技能、已有 v1 作业三种请求走查，没有创建执行聊天或自动化。它复现出原状态助手取消后仍残留活作业、却拒绝再更新的边界问题。通用版增加取消前的暂停/作业结案守卫，回归检查确认拒绝时状态不变、仍能继续清理；原旧助手保持原样用于原运行。

走查还指出旧运行如何采用新模型容易混淆，已在 adapters.md 明确“当前运行显式变更”与“下一轮 v2 使用”两条路径；初始化不会迁移旧状态。配置请求仍不等于实际生效。

支持读取协议、通过本地守卫测试和跨宿主自动执行是不同层面的能力。完整自动化支持范围须在目标宿主实际验收后更新。

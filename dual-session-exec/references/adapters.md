# 宿主适配与模型选择

## 配置选择

主会话和子会话分别接受模型与思考强度，按用户最近明确选择记录；未指定的字段为 null（不传覆盖），不能用空字符串或从另一侧记录复制配置来补齐。已有运行的最新授权优先于模板与旧默认。新运行没有内置模型或强度默认值。宿主自身默认若继承主会话，按该默认行为记录；null 不是强制隔离模型，也不能保证两侧使用不同型号。

示例请求：

> 使用双会话执行已批准计划。主会话保留当前模型和强度，子会话使用我从当前可用列表选择的模型与强度；不支持时先说明。普通模式。

也可以明确提供 `parent_model`、`parent_thinking`、`worker_model`、`worker_thinking`；它们是语义字段，不是所有宿主通用的 API 参数。

启动前从实际工具 schema、模型列表或当前宿主文档核对每个模型的能力。记录来源与时间；不要在技能内维护易过期的模型白名单。若列表不可读取，由用户在宿主界面选择并报告，记录为用户确认，不能伪造工具证据。可用性未知时只准备契约，不启动依赖显式配置的工作。

| 情况 | 行为 |
|---|---|
| 用户不指定某侧某字段 | 记录 null，省略该覆盖项，报告宿主默认尚未确认 |
| 子代理的宿主默认是继承主会话 | 允许保持真实默认，注明继承来源；不因此擅自选择另一模型，也不称已独立指定 |
| 宿主可设置所选模型/强度 | 使用该侧原生控制；保存请求与观察到的运行证据 |
| 无主会话切换工具 | 告知用户需在当前会话界面切换；在确认前不执行受该选择影响的工作 |
| 子代理角色锁定模型 | 说明与所选值是否一致；不使用锁定角色冒充可选模型 |
| 所选模型不支持强度参数 | 说明该字段不受支持；请用户修改选择或明确接受宿主默认，不能静默删掉显式参数 |
| 配置只有请求回执 | 标为 requested，runtime_confirmation 保持 null |
| 中途修改一侧配置 | 暂停受影响工作，更新授权来源和配置版本，清空该侧旧确认；同身份恢复并观察新轮次 |

强度值只在该模型支持时传入；布尔思考开关、预算 token 和 high/max 等级没有通用换算。不从模型名称推断价格、质量或思考能力。不要求用户交出 API 密钥给技能脚本。

## 能力映射

选择后在 contract/session 中记录实际 adapter、会话类型、能力来源和以下操作的真实工具或用户步骤：create、identify、resume、send、receive、status、pause-writes、model-control、wake、cleanup。缺少哪一项就说明哪一项，不能发明接口。

- 原生独立聊天：遵守宿主对创建新聊天、向旧聊天发消息的授权要求。某些工具的模型参数影响接收方，回报主会话时省略模型和强度。
- 受管子代理：只在宿主规则及用户授权允许时使用。预先核对子代理是否能选择模型、是否继承上下文、是否会随父轮次结束、是否可持久恢复。创建时只传契约所需内容，不能把所有父历史当必要输入。
- 用户中转：主会话输出完整启动消息、执行侧入口和契约；用户创建第二聊天并选择模型。执行者报告可核查 ID，无法读取时由用户分配唯一逻辑 ID 并标为 manual_identity。两方各自保存同一 run_id 的记录；不假定跨机绝对路径可读，发送所需的文件或全文。交接使用编号差异消息，用户确认转交后再由接收方记录消费。没有宿主定时器就约定用户手动继续。

没有独立执行能力且用户未选择中转时，止于准备好的启动包与待办，不把单一会话的角色扮演称为独立验收。

## 继续旧运行

已有 v1 session 或正在运行的作业，先按原契约、原身份和原 helper 检查状态，不运行 v2 init/select 覆盖它。仅更换技能文件不改变旧运行的模型、模式或作业。若用户明确要求当前旧运行换模型，可由主会话在暂停相关写入、核对作业后，原子更新旧 session 对应角色的最新授权（保留其余字段及原格式；worker 的两字段仍须非空），清除过期运行确认，并用真实宿主控制恢复同一会话验证新轮次。主侧仍不通过子会话回报覆盖配置。

无法支持的新设置须记录为 pending_config_change 并暂停依赖工作；若用户只希望用于未来运行，则留给下一个 v2 run，当前运行继续旧设置。两种情况明确区分，不把新配置追认到已经执行的轮次。协议/模式迁移需要单独的具体交接，不能自动重启或创建替代执行者。

## 工具参数边界

`scripts/message_args.py` 只为 Codex 桌面的 `send_message_to_thread` 生成参数，不发送消息。其他宿主按当前接口分别映射；不可把该 JSON 直接交给未知工具。消息正文只描述工作，不充当模型控制接口。人工或跨宿主方案需自己保存真实中转回执，不承诺自动唤醒。
